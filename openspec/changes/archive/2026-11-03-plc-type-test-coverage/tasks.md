# Tasks

Every task adds a characterization test of existing behavior (design D1). The test must pass on the current code. The red step is the mutation check of D1: change one expected value, see the failure name the case, and restore the value.

When a new test fails on the current code, stop the task. Report the case, the expected value, and the actual value as a finding. Do not change production code. Do not change the expected value without a decision of the user.

After each task, run `cargo clippy --workspace --all-targets --all-features --locked -- -D warnings`, `cargo test --workspace --all-features --locked`, and `cargo fmt --all --check`. The `recipe-db` tests need Docker.

Every task that writes a test goes to a Sonnet agent. Only task 1.5 is `[mechanical]` (design D6).
