# Tasks: app-use-cases-and-ports

Each code task starts with a failing test. Run it, see it fail, and keep the output. Then write the code. A task that only adds tests for finished code reports "first run passed". After each code task, run the clippy, test, and fmt commands of `openspec/config.yaml`, section `operations.apply.guidance`. A `[mechanical]` task goes to a Haiku subagent. Sonnet does every other code task. `target/p23-brief.md` is the common brief of the subagents.

The ste-lint command is the last command of the section "Local checks" of `CONTRIBUTING.md`. The module `memory` compiles under `cfg(test)`, so its check commands need no feature flag (design D2).

Each use case task tests the success path, its audit entries, and its lock journal against `data-model.md` section 6. It tests each error of its row in `domain-model.md` section 5, or names the task that tests a shared error. It also tests that the domain method uses the locked state (design D10) and that a failed command writes nothing.
