# User guide

This user guide explains how to use the recipe editor. It serves the Administrator, the Process engineer, and the Operator. See [Permissions by role](reference-permissions.md).

## Tutorial

Read the tutorial when you use the editor for the first time.

- [First recipe in 15 minutes](tutorial-first-recipe.md): Create a recipe, get it approved, and export it.

## How-to guides

Read a how-to guide when you need to complete one task.

- [Edit a parameter in a draft](how-to-edit-a-parameter-in-a-draft.md): Change a value or a process limit and save the change.
- [Approve a version](how-to-approve-a-version.md): Approve a colleague's draft so that a PLC can load it.
- [Compare two versions of a recipe](how-to-compare-two-versions.md): Read the changes between two versions.
- [Add a UDT type to a machine](how-to-add-a-udt.md): Define a new type or a new revision on a machine.
- [How to export a version](how-to-export-a-version.md): Save an approved version as a JSON file.
- [Check an export document before a PLC load](check-export-document.md): For the author of a transfer system. Check a file before a PLC loads it.

## Reference

Read a reference page to look up a page, a permission, or a file format.

- [Screens reference](reference-screens.md): Each page, its route, its actions, and its permission.
- [Permissions by role](reference-permissions.md): The roles and the actions that each role may perform.
- [Export document format](export-format.md): The parts of an export file and their source documents.

## Explanation
