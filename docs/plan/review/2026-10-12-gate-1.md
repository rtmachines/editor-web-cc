## Owner decisions for the second reconciliation (made 2026-10-12 by the author under the accepted recommendations)

| # | Decision |
|---|---|
| G1 | Approval of outdated parameters (B60, draft 38-39): `ApproveVersion` returns `E-RCP-024 TypeRevisionOutdated` unless the request carries `allow_outdated = true`. The approve page lists the outdated parameters and offers the flag. The flag value is written to the audit entry. A29 text is extended |
| G2 | Rebind (B61): one command `RebindTypeRevision { draft, from_type_id, to_type_id }`. It rebinds every parameter of the draft whose type tree contains `from_type_id`, including nested use, maps values and limits by member name, returns `E-RCP-028` or `E-RCP-029` per parameter in a list |
| G3 | "application" (draft 64): new Assumption A37 "`anyhow` is used in the binary crate only. The draft word application means the executable". R33 cites A37 |
| G4 | S7 address (B12): required on `S7_300`, optional on `S7_1200` and `S7_1500`, forbidden on `CodesysIec` and `TwinCat3`. One CHECK enforces the three cases. Export writes the stored value when present |
| G5 | LangCode (B13): `^[a-z]{2,3}(-[A-Z]{2})?$` everywhere |
| G6 | String lengths (B27, C8, C9): one table in domain-model 2.1: `CodesysIec`, `TwinCat3`: STRING 1..255, WSTRING 1..255. `S7_300`: STRING 1..254, no WSTRING. `S7_1200`, `S7_1500`: STRING 1..254, WSTRING 1..16382. CHECK `string_length BETWEEN 1 AND 16382`. `size_bytes INTEGER` |
| G7 | Layout sizes (B28): `size_bytes` is stored for primitives only. `S7Layout` computes struct and array sizes in the domain and does not store them |
| G8 | BOOL in S7 layout (B29): a BOOL parameter is bit-addressed (`DBX<byte>.<bit>`), `size_bytes = 1` is its storage unit. In a struct, consecutive BOOL members pack 8 per byte. The next non-BOOL member starts at the next byte, or the next even byte when it is wider than 1 byte |
| G9 | Alignment (B30): every element wider than 1 byte, every STRING, every struct and every array starts on an even byte. BYTE, CHAR and packed BOOL may start on any byte |
| G10 | Array dimensions (draft 25-26): at most 3 dimensions on every platform. New Assumption A38 and a CHECK |
| G11 | IEC derived types (draft 24): ENUM, subrange and alias types are not supported. New Assumption A39 |
| G12 | Parameter key (draft 18-19): the server generates `key`. It is unique inside a version and stable across versions of one recipe. New Assumption A40 |
| G13 | Login order (B35, B36, C10): acquire the Argon2 permit, then T1 under the advisory lock: count failures, insert the attempt row with `succeeded = false`, commit. If throttled: release the permit, respond. Then Argon2. Then T2: update the attempt row and create the session, or write `security_event` |
| G14 | Export hash (B50–B52, C5–C7): the hashed body contains identifiers and values only: `machine.code`, `machine.plc_platform`, `recipe.reference_number`, `version.number`, `types[]`, `parameters[]`. Outside the hash: `schema_version`, `exported_at`, `exported_by`, `loadable`, `version.status`, `version.approved_at`, `version.approved_by`, `machine.name`, `recipe.name`, `content_sha256`. Every numeric leaf and every limit is a JSON string with the canonical decimal text. `parameters[].type_id` is the field name. The stored hash is compared on every export, Approved or Retired |
| G15 | `EnsureDerivedType` (B24): an internal operation of the Plant Model, called by `AddParameter`, `UpdateParameterDefinition`, `DefineUdt`. Not a use case, no permission row. The command list has 33 use cases plus this internal operation |
| G16 | Audit chain (C1–C3, C15): table `audit_chain_head (singleton, last_seq, last_hash)` locked `FOR UPDATE` in the trigger; `audit_log.chain_seq BIGINT NOT NULL UNIQUE` assigned from it; `entry_hash = sha256(prev_hash || canonical)` where canonical is the JSON of the fixed column list with timestamps as epoch microseconds; verification orders by `chain_seq` and recomputes every hash with `SET TimeZone = 'UTC'`. 0003 grants CREATE on `public` to `audit_owner` for the ownership transfer and revokes it after |
