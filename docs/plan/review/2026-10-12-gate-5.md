## Decisions for the sixth reconciliation (author, 2026-10-12)

| # | Decision |
|---|---|
| L1 | **Leaf classes and time values.** data-model 7 gets a column `class` per primitive: `numeric` (SINT, USINT, INT, UINT, DINT, UDINT, LINT, ULINT, BYTE, WORD, DWORD, LWORD, REAL, LREAL), `string` (STRING, WSTRING), `bool` (BOOL), `char` (CHAR, WCHAR), `duration` (TIME, LTIME, S5TIME), `instant` (DATE, LDATE, TIME_OF_DAY, LTOD, DATE_AND_TIME, LDT, DTL). A `duration` or `instant` leaf is stored, hashed and limited as an integer count of its base unit, as a decimal text: TIME = milliseconds (i32 range), LTIME = nanoseconds (i64), S5TIME = milliseconds restricted to the S5 time bases (10 ms..9 990 s, granularity 10 ms/100 ms/1 s/10 s by range), DATE = days since 1970-01-01, LDATE = nanoseconds since 1970-01-01, TIME_OF_DAY = milliseconds since midnight (0..86 399 999), LTOD = nanoseconds since midnight, DATE_AND_TIME = seconds since 1970-01-01 (S7 range 1990-01-01..2089-12-31), LDT and DTL = nanoseconds since 1970-01-01. `ProcessLimit.min/max` apply to `numeric`, `duration` and `instant` leaves in the same base unit. `string` leaves use `max_length`. `bool` and `char` leaves have no limit (A36 extended: "BOOL, CHAR and WCHAR leaves have none"). The UI accepts and shows IEC literals (`T#1d2h3m4s5ms`, `LT#…`, `S5T#…`, `D#2026-10-12`, `TOD#12:30:00.500`, `DT#2026-10-12-12:30:00`, `LDT#…`, `DTL#…`) and converts them with the `recipe-domain` parser `IecLiteral` (own code, no external crate). `char` values are one Unicode scalar (CHAR: U+0000..U+00FF). New Assumption A43 records the base units. The export document carries the decimal text and the consumer gets the unit from the type name (api 6 unit table) |
| L2 | Every form and preview route is a query use case with the permission of the command it prepares: `GetMachineForm`, `GetUnitForm`, `GetUdtForm`, `GetRecipeForm`, `GetVersionForm`, `GetParameterForm`, `GetApprovalPreview`, `GetUserForm`. They are listed in domain-model 5.5 and in the matrix with the command's permission. The HTTP layer still only authenticates |
| L3 | **Lock order:** `machine` → `recipe` → `recipe_version` → `unit` → children. Every command that reads or writes rows of one machine takes the machine lock first: `FOR NO KEY UPDATE` in `RenameMachine`, `ArchiveMachine`, `ArchiveUnit`, `RenameUnit`; `FOR SHARE` in `AddUnit`, `CreateRecipe`, `RestoreRecipe`, `CreateVersion`, `AddParameter`, `UpdateParameterDefinition`, `RebindTypeRevision`, `DefineUdt` (then the advisory lock). `plc_type.machine_id` FK then takes FOR KEY SHARE on a row the command already holds, so no cycle. ADR-0015 states the order and the two cycles it closes. A concurrency test runs ArchiveUnit against AddParameter with a new derived type |
| L4 | **Flood bound.** `login_attempt` rows are written only until the per-IP budget is reached; after that the throttled response is served from the budget row and writes nothing. `security_event` rows for `login_failed`, `login_throttled`, `csrf_rejected` are aggregated per (`client_ip`, `kind`, minute): one row with a `count` column, updated in place (column grant `count`). In read-only mode (A24) the Login path writes `login_attempt` and `security_event` only for successful logins; failures are logged to the event log only. `security_event_purge()` deletes in batches of `security_event.purge_batch` (5 000) rows per statement |
| L5 | **Chain check.** The job reads the head first, then verifies rows with `chain_seq <= head` in batches bounded by `audit.check_batch_bytes` (8 MiB of `before_state`/`after_state`) and `audit.check_batch` rows, each batch its own statement and its own short transaction (no long snapshot); `SET LOCAL statement_timeout` = `audit.check_statement_timeout` (60 s) per batch. Progress keys as before. `audit.max_check_age` = 26 h |
| L6 | WAL health = replication lag: `pg_current_wal_lsn() - sent_lsn` from `pg_stat_replication` for `recipe_replicator` < `wal.max_lag_bytes` (16 MiB) and the receiver connected. The app writes a heartbeat row to `app_setting` (`heartbeat.last_at`) every `heartbeat.interval` (5 min) so WAL is never idle for long |
| L7 | New codes `E-PLT-019 MachineNotFound { code }` (404) and `E-PLT-020 UnitNotFound { path }` (404) for request fields that name a machine or unit. Added to CreateRecipe, RestoreRecipe (machine), AddUnit (parent), AddParameter, UpdateParameterDefinition (unit). `E-WEB-005` stays for URL values only |
| L8 | Advisory locks use the two-key form `pg_advisory_xact_lock(class, key)`: class 1 = login (`hashtext(login)`), class 2 = derived types (`hashtext(machine_id::text || ':' || name)`), class 3 = audit head (if ever needed). Documented in data-model 1 |
| L9 | C5, C7, C8, C9, C12, C13 and every cosmetic item as written |
| L10 | B1–B6 as written |
