## Cosmetic items (fix the ones that can mislead an implementer)

- api 373 "Names are not hashed" but `parameters[].name_en` is hashed (api 351): decision H4 says `name_en` is NOT in the hash.
- Address grammar shows `[.<bit>]` optional (domain-model 124), CHECK requires the bit for X: make the grammar say "bit required with X, absent otherwise".
- Overlap scope: "of one machine" (domain-model 138) vs "of one version" (ADR-0017:58): the rule is per data block inside one version.
- data-model 6 error columns omit MachineArchived (AddUnit), DerivedTypeInvalid (DefineUdt), PasswordPolicy (ResetPassword, ChangeOwnPassword).
- 7.11 missing values: container limits, `Retry-After: 5`, HSTS max-age, PostgreSQL settings, ordinal ≤ 100000, app_setting value ≤ 1000.
- data-model 1538 "a migration can delete a row" vs trigger 4.6 blocks DELETE for every role: say "a migration disables the trigger, deletes, re-enables".
- S7 layout scope: I20 says S7-300 only, A31 says every address: the width, alignment and overlap checks run on every platform that has an address.
- Translation description limit: same as English (0..4000, may be empty).
- ADR-0013:47 cites the superseded ADR-0011 → ADR-0021. ADR-0005:44 one approval entry vs data-model two: data-model is right (VersionApproved + VersionRetired).
- Minor: `ConcurrentEdit` fields, `Tx::commit` vs `UnitOfWork::commit` (use `UnitOfWork::commit`), ADR-0016:49 `&DraftEditors`, lock statement columns, ChangeOwnPassword wording, seed description, weak citations A16/A3.
